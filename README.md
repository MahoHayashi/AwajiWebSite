# Awaji Trip Guide

兵庫県・淡路島の観光スポットとグルメを紹介する 1 ページ完結型のランディングページです。Figma でデザインしたカンプをもとに、HTML / CSS / JavaScript のみで実装しました。

🔗 **公開サイト:** https://awaji-trip-guide.vercel.app

## 概要

「観光だけじゃない、ちょっと特別な週末」をテーマに、淡路島の魅力をビジュアル中心で伝える観光ガイドサイトです。海と自然を感じさせる配色（オレンジ・ブルー・ネイビー）と、波形の区切りや足あとのイラストを使った遊び心のあるデザインが特徴です。

## セクション構成

| セクション | 内容 |
| --- | --- |
| **HERO** | ロゴと淡路島の海の背景によるファーストビュー |
| **ABOUT** | 写真とテキストを左右で縦ずらしに配置した島の紹介 |
| **MAP** | 淡路島のマップイラスト上にアイコンを配置し、各スポット名と線でつなぐインタラクティブなマップ |
| **SPOT** | 観光スポット 3 件（Hello Kitty Smile / パルシェ 香りの館 / イングランドの丘）の紹介カード |
| **GOURMET** | グルメ 3 件（miele / 幸せのパンケーキ / 玉ねぎ倉庫跡地 志知カフェ）の紹介カード |
| **MODEL PLAN** | 11:00〜18:00 の 1 日モデルプランを足あとイラストでつなぐタイムライン |
| **CTA / FOOTER** | 締めのメッセージとコピーライト |

各スポット・グルメには営業時間、電話番号、公式サイトへのリンクを掲載しています。MAP のスポット名をクリックすると、対応する詳細カードへスムーズスクロールで移動します。

## 主な機能

- **スクロール連動のフェードイン** — `IntersectionObserver` で各セクションをスクロール時にふわっと表示
- **マップのコネクター線** — JavaScript で各アイコンとスポット名の座標を計算し、`div` の回転で線を動的に描画。リサイズ時はデバウンスして再描画
- **ヘッダーの表示制御** — HERO 表示中はナビゲーションを非表示にし、スクロールで表示
- **レスポンシブ対応** — ハンバーガーメニューによるモバイルナビゲーション

## 使用技術

- **HTML5 / CSS3 / Vanilla JavaScript**（フレームワーク・ビルドツールなし）
- **CSS カスタムプロパティ** でカラー・フォント・余白などを変数管理
- **Google Fonts**（Playfair Display / Noto Serif JP）
- **Figma** — デザインカンプ作成。画像アセットの一部は Figma 上から配信
- **Vercel** — ホスティング・デプロイ

## レスポンシブ

- `max-width: 1000px` — タブレット〜PC レイアウトからの切り替え
- `max-width: 390px` — スマートフォン向けの調整

## ディレクトリ構成

```
AwajiWebSite/
├── index.html      # ページ全体のマークアップ
├── style.css       # スタイル（カラー変数・レイアウト・レスポンシブ）
├── main.js         # フェードイン・マップ線描画・ハンバーガーメニュー
└── images/         # 写真・アイコン・イラストなどの画像アセット
```

## ローカルでの確認

ビルド不要の静的サイトです。リポジトリを取得後、`index.html` をブラウザで開くだけで閲覧できます。

```bash
# 簡易サーバーで確認する場合
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## デザインについて

Figma でデザインを作成し、波形の区切り（wave divider）やマップイラスト、足あとなどのオリジナルアセットを制作しました。コーディングはデザインカンプに忠実に再現することを目指しています。ワイヤーフレームも Figma で作成しています。
